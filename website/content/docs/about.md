The Dynamic PDB is a sandbox database for studying variation in biomolecular structure. It connects experimental data with structural models, processing records, and reported quality scores. Researchers can examine alternative models of the same dataset and trace the evidence and methods behind them.

## What you can do

- **Find and inspect models.** Browse public entries and view structures in your browser.
- **Compare results.** Examine models linked to the same experimental data and their reported quality scores.
- **Trace their origin.** Inspect recorded input files, processing steps, and software versions.
- **Access data.** Download individual files and retrieve public records through the API.

## Current scope

The Dynamic PDB is under active development. Current entries primarily cover X-ray crystallography, with a data framework intended to support additional experimental methods. Models can represent a single conformation, multiple conformations, or an ensemble of structures.

The database stores or references results produced by external tools. It does not perform model building or refinement. Available files, processing records, and quality scores vary by entry.

## Privacy

We count visits, searches, viewer use, and file downloads with [Umami](https://umami.is/), a privacy-focused analytics tool. It sets no cookies and collects no personal information. We use the totals to understand how the database is used and to report on it.

The Dynamic PDB is supported by [Prism](https://prismscience.org/), a program of [Radial](https://radial.org/), a division of the [Astera Institute](https://astera.org/).
